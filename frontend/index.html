WHAT is it?

NECRO is a multi-agent forensics system that scans your GitLab commit history using Google Cloud Agent Builder and GitLab MCP to find features, flags, and merged work that was disabled or shelved — then determines which ones are ready to revive based on whether the original kill reason still applies today.

WHY does it matter?

Decisions expire. The constraint that killed a feature in 2022 may have dissolved in 2023 — but nobody checks. Code stays dead. Teams reinvent. Estimates: $140K+ wasted per year per 25-developer team.

HOW does it work?

  1. Phase 0 — Agent Builder autonomously assesses the repo: calls list_commits via MCPToolset, decides optimal scan depth, streams reasoning live.
  2. Phase 1 — 6 forensic strategies detect dead features via GitLab MCP. Gemini 3 Flash analyzes kill reasons with live constraint grounding. An independent Vertex AI challenger stress-tests every revival case.
  3. Phase 2 — Agent Builder synthesizes all findings into a ranked executive action plan. One click creates a GitLab issue or Draft MR with a revival checklist.
